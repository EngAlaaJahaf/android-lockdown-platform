# دليل المدير — ADMIN_GUIDE

## الأدوار (§30)
| الدور | الصلاحيات |
|---|---|
| SUPER_ADMIN | كل شيء بما فيه تفويض العمليات الحساسة |
| DEVICE_ADMIN | تسجيل/فحص/تشخيص الأجهزة |
| POLICY_ADMIN | إنشاء/مراجعة/تطبيق السياسات (APPLY يمر بالبوابات) |
| AUDITOR | قراءة الأدلة والتدقيق + فحص السلسلة |
| READ_ONLY | عرض فقط |

## سير العمل الطبيعي
1. **الاكتشاف**: وصّل الجهاز → يظهر في القائمة تلقائيًا مع بطاقته الحقيقية.
2. **المعاينة**: اختر السياسة → اعرض (الحالية/المستهدفة/المخاطر/الطريقة/المتطلبات/الاسترداد).
3. **Preflight**: الهوية + القدرات + التوافق + الاسترداد + الاتصال + الأمان + التخزين + الأذونات — أي فشل حرج = STOP.
4. **التطبيق**: يتطلب الدور + الموافقة (حساسة) + شهادة الحيازة → `EV-/AUD-`.
5. **التحقق**: قراءة حية → مطابقة → COMPLIANT/PARTIAL/NON_COMPLIANT/UNKNOWN (لا PASS مزيف).
6. **الاسترداد**: R1 مع تحقق لاحق إلزامي قبل اعتبار الجهاز متوافقًا (§41).

## المحظورات
- لا سياسة تقطع الإدارة بلا قناة استرداد (البوابة تمنع تلقائيًا).
- لا عملية مدمرة (إعادة ضبط/تقاعد/فريمور/إلغاء تسجيل) بلا تأكيدين مسمّيين.
- لا R3 (فلاش) من التطبيق أبدًا — مختبر فقط.
