# الأمان — SECURITY

(المرجع الكامل: `docs/SECURITY_ARCHITECTURE.html` — هنا الخلاصة التشغيلية)

## الطبقات
1. **RBAC**: خمسة أدوار (`SUPER_ADMIN → READ_ONLY`) بقرارات ALLOW/DENY/REQUIRES_APPROVAL لكل عملية.
2. **لا كلمة رئيسية**: عامل الحيازة شهادة 256-بت لكل جهاز (AES-256-GCM، مفتاح HKDF، جذر DPAPI).
3. **عمليات حساسة**: 9 عمليات (منها `FACTORY_RESET/RETIRE/FIRMWARE/UNENROLL` بقاعدة مزدوجة).
4. **تدقيق**: سلسلة SHA-256 إلحاقية + حجب أسرار تلقائي + `tamper_check()`.

## ما هو مضمون / غير مضمون (§56)
- مضمون: التفويض، الموافقات المزدوجة، تشفير الشهادات في الراحة، كشف العبث في السجلات.
- غير مضمون: منع الهندسة العكسية 100% (الهدف: رفع كلفة الهجوم + كشف العبث)،
  أمان قناة شبكية مستقبلية (تصميم فقط)، تدقيق خارجي (مجدول PHASE 14).

## ممنوعات أمنية
- كلمة مرور مدير كنص صريح — ممنوعة (مخزن آمن/تشفير عند الحاجة).
- أسرار في السجلات — محجوبة إجباريًا (`FORBIDDEN_FIELDS`).
- تجاوز FRP/bootloader/Knox/OEM — محظور تصميمًا (المحركات: آليات إدارة شرعية فقط).
